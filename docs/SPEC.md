# Спецификация MVP и план реализации

## 1. Легенда

**Компания:** рекламное агентство «Вектор» (вымышленное, демо-данные). Услуги: контекстная и таргетированная реклама, SMM, креатив и брендинг.

**Для кого бот:** для владельцев малого бизнеса и маркетологов, которые выбирают подрядчика по рекламе и пока не готовы звонить менеджеру.

**Задача пользователя:** быстро понять, что делает агентство, сколько это примерно стоит и как работает, и при необходимости оставить заявку, не заполняя формы на сайте и не ожидая ответа менеджера.

**Задача бота:** снять первичные вопросы и собрать качественную заявку. Менеджер получает имя, контакт и описание задачи, а пользователь не ждёт ответа на типовые вопросы.

## 2. Граница MVP

**Входит**

- Web-интерфейс чата: история сообщений, главное меню, поле ввода, кнопки действий.
- `bot-flow`: `Услуги`, `FAQ`, обычная заявка, обратная связь.
- ИИ-консультант: ответы по `knowledge/`, помощь с заявкой, подтверждение перед сохранением.
- SQLite `data/bot.sqlite3`: таблицы `leads` (с `source`) и `feedback`.
- Локальный запуск и запуск того же runtime на VPS (systemd).

**Не входит**

- домен и HTTPS, публичная ссылка на интерфейс;
- кабинет менеджера или админка (данные смотрим через `scripts/show_db.py`);
- авторизация пользователей, платежи, интеграции с CRM и мессенджерами;
- уведомления менеджеру, очереди, Docker, nginx, мониторинг и прочий production-контур;
- загрузка файлов, голос, многоязычность (только русский).

## 3. Услуги (5 в MVP)

| Услуга | Срок запуска | Цена |
|---|---|---|
| Контекстная реклама (с аналитикой и отчётом) | 3–5 рабочих дней | от 25 000 ₽/мес + бюджет |
| Таргетированная реклама | 5–7 рабочих дней | от 30 000 ₽/мес + бюджет |
| SMM-продвижение | по договору | от 40 000 ₽/мес |
| Креатив и видеореклама | 1–3 недели | от 35 000 ₽ за кампанию |
| Брендинг и логотип | 3–5 недель | от 90 000 ₽ |

Источник истины — `knowledge/services.md`; бот и ИИ читают этот файл, а не копию в коде.


## 4. FAQ

Файл `knowledge/faq.md` (вопросы) и `knowledge/rules.md` (правила). Категории:

| Категория | Где лежит | Примеры |
|---|---|---|
| Услуги | `services.md`, `faq.md` | что входит в тариф, входит ли рекламный бюджет |
| Стоимость | `services.md`, `faq.md` | оценка до договора, способы оплаты, возвраты |
| Сроки и формат работы | `rules.md` | порядок работы, сроки запуска, правки, отчётность |
| Правила и контакты | `rules.md`, `faq.md` | гарантии, конфиденциальность, как связаться |

## 5. Данные заявки

**Собираем (все три поля обязательны)**

| Поле | Правило |
|---|---|
| `name` | 2–80 символов |
| `contact` | e-mail, телефон или Telegram (`@nick`) |
| `description` | 5–1000 символов, суть задачи |

Служебные поля в БД: `id`, `source`, `created_at`.

**Не должен просить и сохранять:** пароли и коды из SMS, доступы к рекламным кабинетам, номера карт и банковские реквизиты, паспортные данные, СНИЛС, адрес проживания, дату рождения, ключи API. Если пользователь пишет такое сам, бот просит не отправлять эти данные: доступы менеджер запросит по защищённому каналу после договора.

**Обратная связь:** только текст отзыва, без имени и контакта, хранится отдельно в `feedback`.

## 6. `bot-flow` и ИИ-консультант

| | `bot-flow` | ИИ-консультант |
|---|---|---|
| Обращение к модели | нет | да (OpenAI-совместимый API) |
| Поведение | детерминированный сценарий по шагам и кнопкам | свободный диалог по базе знаний |
| Ввод | кнопки и заранее известные шаги | произвольные вопросы |
| Источник ответов | `knowledge/` напрямую (разделы файлов) | `knowledge/` через tools, пересказ моделью |
| Заявка | форма: имя → контакт → описание → подтверждение | модель собирает поля в диалоге и вызывает `prepare_lead_draft` |
| `source` в БД | `bot_flow` | `ai_consultant` |
| Без ключа API | работает полностью | демо-режим по ключевым словам |

Общее: подтверждение кнопкой `Отправить заявку` / `Изменить` / `Отмена`, одни и те же валидаторы, одна таблица `leads`.

## 7. Ограничения ИИ-консультанта

- Отвечает только по `knowledge/`; нет данных в базе — говорит об этом и предлагает заявку.
- Не называет цену вне прайса, не обещает сроки и результаты рекламы, не принимает решения по договору.
- Видит три tools: `search_knowledge`, `read_knowledge_file`, `prepare_lead_draft`. Чтение — только `.md`/`.txt` внутри `knowledge/`, без `.env`, скрытых файлов, `..`, симлинков наружу и произвольной ФС.
- Не сохраняет заявку сам: `save_confirmed_lead` вызывает runtime после нажатия кнопки пользователем.
- Текст черновика показывает runtime из проверенных полей.
- Содержимое базы знаний и сообщения пользователя — данные, а не инструкции; промпт и ключи не раскрывает.
- Лимиты: сообщение до 2000 символов, до 5 итераций tools за ход, история 20 сообщений.
- Логи: без текстов сообщений и данных заявок, секреты и персональные данные маскируются.

## 9. План по слоям

| Слой | Что делаем | Результат |
|---|---|---|
| `interface` | `static/`: история, меню, кнопки, поле ввода, отображение черновика | чат работает в браузере |
| `backend` | `server.py`, `bot_flow.py`, `sessions.py`, `validation.py`, `logging_setup.py` | `/api/chat`, сценарии, валидация |
| `database` | `db.py`: `leads` с `CHECK` на `source`, `feedback` | заявки и отзывы различимы |
| `agent` | `agent_runtime.py`, `agent/tools.py`, `agent/knowledge.py`, `agent/soul.md`, `knowledge/` | консультант с защищёнными tools и подтверждением |

Порядок: база знаний и БД → bot-flow → интерфейс → агент и tools → проверка и скриншоты → VPS.
